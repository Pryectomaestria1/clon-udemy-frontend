# Udemy Clone - Frontend (React)

Interfaz de usuario moderna y responsiva inspirada en Udemy, diseñada para una experiencia de aprendizaje fluida.

## 🚀 Tecnologías
- **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Lenguaje:** TypeScript
- **Estado Global:** React Hooks
- **Autenticación:** [@auth0/auth0-react](https://auth0.com/docs/libraries/auth0-react) (OIDC con PKCE)
- **Estilos:** Vanilla CSS (Custom Design System)

## 🏁 Instrucciones para Correr
1. **Instalar dependencias:**
   ```bash
   npm install
   ```
2. **Ejecutar en modo desarrollo:**
   ```bash
   npm run dev
   ```

La aplicación se abrirá en `http://localhost:5173`. Asegúrate de que el backend esté corriendo en el puerto 3000 para la persistencia de datos.
